# Test

## Master Dashboard

A self-contained, zero-dependency master dashboard built with vanilla HTML, CSS,
and JavaScript. Open `index.html` in a browser — no build step or server
required.

### Features

- KPI cards (revenue, users, orders, conversion rate)
- Revenue trend line chart with 7d / 30d / 90d range toggles
- Traffic-source donut chart with legend
- Recent orders table and activity feed
- Sidebar navigation, search, and refresh
- Responsive layout for narrow screens
- Hi-DPI canvas rendering

### Files

- `index.html` — markup and layout
- `styles.css` — dark theme and responsive grid
- `dashboard.js` — mock data, charts, and interactivity
